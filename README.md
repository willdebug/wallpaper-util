# Introduction
This is a very simple utility for changing the hyprpaper wallpaper and running matugen aimed at streamlining this very mundane task.
# Usage
To use this just run wallpaper-util in the terminal and a file select window should come up. Select the picture that you want to be your wallpaper
# Important 
This only works if you use hyprpaper for your wallpaper and matugen for colours otherwise the wallpaper-util command will fail
